# AstrBot 赞助回复插件

一个面向 QQ 群的 AstrBot 独立插件：群友普通提到“赞助”时，机器人会 @ 对方并提示可用指令；只有完整输入指定指令时才会发送对应图片。

本仓库不包含任何收款码、二维码或私人图片。安装后请在插件配置页上传自己的图片。

## 功能

- 普通消息包含“赞助”时，@ 发送者并发送文字提示。
- 完整输入“赞助微信”或“赞助支付宝”时，发送管理员上传的对应图片。
- 支持一组自定义指令和自定义图片，例如“赞助爱发电”。
- 支持微信群提示冷却时间，避免连续刷屏。
- 群聊中以机器人唤醒词开头或 @ 机器人提问的消息会自动放行给主对话，不会被“赞助”关键词截断。
- 所有图片均通过 AstrBot 插件配置页面上传，支持 JPG、JPEG、PNG、WEBP。

## 安装

### 方式一：AstrBot 面板安装

在 AstrBot 插件页面选择从 GitHub 安装，填写：

```text
https://github.com/luobp1/astrbot_plugin_sponsor
```

安装后启用插件并打开配置页面。

### 方式二：手动安装

将本仓库下载为 ZIP 并解压为 `astrbot_plugin_sponsor` 文件夹，放到 AstrBot 的 `data/plugins` 目录中，重启 AstrBot。

## 配置

1. 在“微信发送图片路径”点击“管理文件”，上传微信二维码。
2. 在“支付宝发送图片路径”点击“管理文件”，上传支付宝二维码。
3. 保存配置。只有完整输入“赞助微信”或“赞助支付宝”时，机器人会发送对应图片。

可选自定义图片：

```text
自定义图片指令：赞助爱发电
自定义指令发送图片路径：上传爱发电二维码或宣传图
```

群友完整输入 `赞助爱发电` 后，会收到该自定义图片。

## 触发规则

| 群友消息 | 结果 |
| --- | --- |
| 我想赞助 | @ 该群友，并提示“请回复‘赞助微信’或‘赞助支付宝’” |
| 赞助微信 | 发送上传的微信图片 |
| 赞助支付宝 | 发送上传的支付宝图片 |
| 萝卜，赞助有什么用 | 交给主机器人正常回答，不触发本插件 |

## 隐私提醒

不要将个人收款码、手机号、身份证明或其他私人文件提交到 GitHub。图片应只通过你自己的 AstrBot 配置页面上传。
